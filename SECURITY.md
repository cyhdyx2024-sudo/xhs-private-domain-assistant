# Security Policy

## Supported version

Security fixes are applied to the latest release and the current `main` branch.

## Reporting a vulnerability

Please do not open a public issue for vulnerabilities involving authentication bypass, cross-tenant access, secret exposure, unsafe external requests or unintended message sending.

Use GitHub's private vulnerability reporting / Security Advisory flow for this repository. Include:

- affected version and component;
- reproduction steps or a minimal proof of concept;
- expected and actual behavior;
- potential impact;
- any suggested mitigation.

Do not include real customer conversations, API keys, workspace tokens, cookies or personal information. Maintainers should acknowledge a complete report within seven days; this is a best-effort open-source target, not a service-level agreement.
