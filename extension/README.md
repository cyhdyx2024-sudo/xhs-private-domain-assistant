# 小红书网页端/专业号私信智能自动回复插件 (XHS Auto-Reply Pro)

## V1.0.1 安全补丁

- **[P1] 拟人化兜底重写**：检测到服务端返回固定模板或鹦鹉学舌时，自动触发 LLM 低温重写（temperature 0.3），固定话术仅在模型彻底不可用时使用。
- **[P1] 知识库账号索引加固**：新增 extractAccountFromHeader()，优先从页面顶部右上角锁定店铺小红书号，避免 DOM 顺序变化导致按客户号建库或串库。
- **[P1] 隐藏会话隔离**：待回复队列只读取可见会话卡片，虚拟巡检只操作当前可见且真实可滚动的列表，避免旧列表反复触发“超时未回复”。
- **[P1] 外部状态转人工**：全自动遇到“加了没/发了吗/申请通过没”等无法从会话核验的动作状态时不自动猜测，暂停该会话 30 分钟并交给人工。
- **[P0] 鉴权自愈与停机**：失效工作区 Token 可重新注册；运行中遇到 401/403 会立即关闭并要求重新配置。
- **[P0] 请求退避**：同一消息失败至少 60 秒后再试；429、5xx 和网络异常指数退避。
- **[P0] 自动回复时限**：全自动只处理默认两小时内且时间可确认的消息。
- **[P0] 显式无人值守**：选择全自动不会直接启动，必须点击“开始无人值守”；人工操作立即退出。
- **[P1] 巡检与排除**：完整列表滚动显示覆盖数，默认排除注销、系统和企业员工会话，并支持黑名单。
- **[P1] 凭据导出加固**：线索导出改用 Authorization 请求头，不再把工作区令牌写入 URL、浏览器历史和访问日志。
- **[P2] 业务资料软停用**：停用业务资料前增加确认弹窗，请求体携带 soft: true 标记，确保后端执行软停用而非永久删除。
- **云端 URL 已内置**：setup wizard 不再暴露云端服务地址，用户只需填写工作区名称、API Key、业务资料和偏好。

专为小红书创作者服务平台与专业号/千帆客服工作台（`creator.xiaohongshu.com`、`pro.xiaohongshu.com`、`customer.xiaohongshu.com`、`qianfan.xiaohongshu.com`）打造的**浏览器端智能私信助手**。
浏览器只负责读取当前专业号会话、生成/预填/发送和展示监控；话术由独立 Agent 调用 LLM 生成。支持**多轮上下文、会话隔离、半自动副驾、谨慎的全自动值守、人工反馈学习和案例索引**。

## 核心功能与亮点

1. **多轮上下文与会话隔离**：
   - 使用当前会话的 UID/data-key，而不是只用昵称；
   - 生成前后再次核对客户和消息签名，切换客户时丢弃过期结果；
   - 案例知识空间按小红书账号 + 业务线隔离。
2. **半自动副驾与谨慎全自动**：
   - 半自动只预填草稿，人工确认后发送；
   - 全自动带人工操作暂停、每小时上限、冷却时间、发送前核验和发送后页面回读；
   - 仅点击按钮但未读回成功消息时，不自动重发，避免重复触达。
3. **真实 LLM 上下文回复**：
   - Agent 接收按时间排序的多轮客户/客服/卡片消息；
   - 对价格、功能、联系方式等硬事实不擅自编造；
   - 对“在吗/没收到”等短消息优先自然承接，避免重复销售和重复索要联系方式。
4. **人工校准与持续学习（V11）**：
   - 半自动模式生成草稿后，人工可直接修改输入框话术并写回本地知识库；
   - 可填写“为什么这样回更好”，留空时由模型自动提炼客户意图、回复策略与避坑点；
   - 相似新会话会检索人工优质案例，只学习表达与策略，不把历史价格、功能或客户身份当作当前事实；
   - 联系方式会在落库前脱敏，知识库存放于 `server/data/xhs_reply_feedback.sqlite3`。
5. **线索识别与运行监控**：
   - 识别客户主动提供的手机号/微信号并预填专业号客资栏；
   - 控制台显示 LLM 成功/失败、耗时、发送成功和发送回读失败次数。

## 给试用客户的安装指引

把插件目录打成 ZIP 发给客户。客户按下面顺序操作：

1. 解压 ZIP，Chrome 打开 `chrome://extensions/`，开启「开发者模式」。
2. 点击「加载已解压的扩展程序」，选择解压后的插件目录。
3. 固定工具栏里的「私信智能顾问」，点击图标进入首次设置。
4. 依次填写：工作区名称 → 模型服务商与自己的 API Key → 店铺资料 → 回复偏好。云端地址已由产品自动配置，用户不需要填写。
5. 配置完成后总开关仍是关闭状态；打开小红书专业号私信页，先开启「半自动副驾」检查至少 20 条真实会话。
6. 确认身份识别、业务事实和话术稳定后，再由客户主动开启全自动。全自动不会因安装或刷新自动开启。

客户的模型 Key 保存在其 Chrome 本地存储中；生成回复时会经专属 Bridge 临时转发给所选模型厂商，云端数据库不保存明文 Key。每个客户首次设置时创建独立工作区令牌、业务资料和反馈知识空间。

进入小红书页面右下角「知识库」后，可以：

- 拖入 PDF、DOCX、PPTX、TXT、Markdown、CSV（单文件不超过 10MB）；
- 粘贴飞书 Docx/Wiki 链接；私有资料需在设置中填写企业自建应用 App ID/Secret，并给应用开通文档读取权限；
- 查看每份资料的版本、解析状态、分段数、索引模式，并软停用或恢复；
- 查看半自动人工优质案例，业务资料负责事实，人工案例负责表达与策略，两者不会混成一个库。

文件会分段、去重并建立混合检索索引。OpenAI/硅基流动可直接配置向量模型；向量生成失败时界面会显示“仅关键词”，不会把降级状态伪装成向量检索。扫描版 PDF 当前需要 OCR 后再入库。

## 本机开发安装

### 方式 A：Chrome 原生扩展加载（推荐，1 分钟搞定）
1. 打开 Chrome 浏览器，在地址栏输入：`chrome://extensions/`
2. 打开右上角的 **「开发者模式」 (Developer mode)** 开关；
3. 点击左上角的 **「加载已解压的扩展程序」 (Load unpacked)**；
4. 选择本仓库的 `extension` 目录；
5. 点击插件图标，按首次设置向导完成配置；本机 Agent 可把云端地址改为 `http://127.0.0.1:18195`。
6. 打开 [小红书专业号私信](https://pro.xiaohongshu.com/im/multiCustomerService)，页面右下角即可看到悬浮助手。
7. 修改 `content.js` 后必须在 `chrome://extensions/` 点击该扩展的“重新加载”，再刷新小红书页面；仅刷新网页不会更新扩展本体。

## 产品边界

- 半自动是默认模式；全自动必须明确开启，且有人操作页面时暂停。
- 会话列表使用虚拟滚动，插件会在无人操作时逐屏巡检未渲染会话，但不能承诺所有新进线 3 秒内回复；模型调用和拟人打字的常见总耗时约 5–12 秒。
- 当前适合小流量试用。要公开商用，还需要 Chrome 商店签名/审核、账号找回与计费后台、租户管理后台和服务条款。

- `content.js`：唯一维护的核心自动化监控、会话隔离、拟人打字与知识库控制台
- `floating-dock.css`：页面内嵌悬浮控制台与深浅色现代 UI 样式
- `xhs_auto_reply_tampermonkey.user.js`：已停用的兼容占位入口，不参与运行
