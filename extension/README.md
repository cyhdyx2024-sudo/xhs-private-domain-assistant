# Chrome 扩展（`extension/`）

小红书专业号私信智能副驾的浏览器端实现，Manifest V3。当前版本 V1.1.0。

## 版本要点（V1.0.3 → V1.1.0）

- **模块化 Bridge**：服务端拆分为数据库、知识库、模型网关和安全护栏模块。
- **虚拟列表补全**：生成、发送前校验和发送回读前确保消息窗口回到底部，避免漏读最新消息。
- **合规预检**：副驾提示高风险表述；无人值守模式命中时直接转人工。
- **隐私与身份清理**：移除个人业务硬编码，补充准确的 BYOK 数据流说明。

V1.0.2 版本要点：

- **[P0] 默认自托管**：Bridge 服务地址默认值由远程托管改为 `http://127.0.0.1:18195`，与 `server/agent.py` 默认监听地址一致；扩展不再内置任何远程服务地址，数据默认不出本机。
- **[P0] 收敛 host 权限**：移除未使用的远程服务域名授权，仅保留小红书页面、本机地址与模型服务商 API 域名。

V1.0.1 及此前版本要点：

- **[P0] 鉴权自愈与停机**：失效工作区 Token 可重新注册；运行中遇到 401/403 会立即关闭并要求重新配置。
- **[P0] 请求退避**：同一消息失败至少 60 秒后再试；429、5xx 和网络异常指数退避。
- **[P0] 显式无人值守**：选择全自动不会直接启动，必须点击"开始无人值守"；人工操作立即退出。
- **[P0] 自动回复时限**：全自动只处理默认两小时内且时间可确认的消息。
- **[P1] 拟人化兜底重写**：服务端返回固定模板或复读时自动触发 LLM 低温重写，固定话术仅在模型彻底不可用时使用。
- **[P1] 知识库账号索引加固**：优先从页面顶部锁定店铺小红书号建库，避免 DOM 顺序变化导致串库。
- **[P1] 隐藏会话隔离**：待回复队列只读取可见会话卡片，避免旧列表反复触发"超时未回复"。
- **[P1] 外部状态转人工**：遇到"加了没/发了吗/申请通过没"等无法核验的动作状态时暂停该会话并交给人工。
- **[P1] 凭据导出加固**：线索导出使用 Authorization 请求头，不把工作区令牌写入 URL 与访问日志。
- **[P2] 业务资料软停用**：停用前确认，请求体携带 `soft: true`。

## 开发安装

1. Chrome 打开 `chrome://extensions/`，开启**开发者模式**。
2. 点击**加载已解压的扩展程序**，选择本仓库的 `extension` 目录。
3. 先启动后端网关：`cd ../server && python3 agent.py`（默认 `http://127.0.0.1:18195`，扩展默认值与此一致，无需额外配置）。
4. 点击插件图标完成首次设置：工作区名称 → 模型服务商与 API Key → 店铺资料 → 回复偏好。
5. 打开 [小红书专业号私信](https://pro.xiaohongshu.com/im/multiCustomerService)，右下角即为悬浮助手。
6. 修改代码后必须在 `chrome://extensions/` 点击本扩展的"重新加载"，再刷新小红书页面；仅刷新网页不会更新扩展本体。

## 建议的启用顺序

1. 先用**半自动副驾**核对至少 20 条真实会话：身份识别、业务事实、话术质量。
2. 确认稳定后，如需值守能力再由操作员显式开启全自动，并了解其约束（冷却、每小时上限、人工操作即暂停、外部状态转人工）。
3. 知识库入口在页面右下角「知识库」：支持 PDF/DOCX/PPTX/TXT/Markdown/CSV（单文件 ≤ 12MB）与飞书 Docx/Wiki 链接；向量模型可选，失败时明确降级为"仅关键词"。

## 文件结构

- `manifest.json`：MV3 配置（权限仅限小红书页面、本机 Bridge 与模型 API 域名）
- `content.js`：核心自动化监控、会话隔离、拟人打字与知识库控制台
- `safety.js`：独立安全规则模块（熔断、时限、黑名单、统计等纯函数）
- `options.html/js`、`popup.html/js`：Studio 管理后台与工具栏弹窗
- `floating-dock.css`：页面内悬浮控制台样式（深浅色自适应）
- `test_release.mjs` / `test_safety.mjs`：契约与安全规则测试（`node` 直接运行）
