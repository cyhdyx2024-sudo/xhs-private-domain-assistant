# 新作 AI 2.0 官方产品手册与核心问答知识库 (Product Manual & Knowledge Base)

## 一、产品定位与核心价值
- **产品名称**：新作 AI（新作 2.0）
- **核心定位**：专为中小企业主、本地生活门店（美业/家装/教培/摄影等）及高客单创作者打造的 **AI 内容与获客图文生产线**。
- **与普通 AI 写作工具的区别**：
  1. 市面大模型（ChatGPT/DeepSeek 等）只负责生成纯文本，不解决小红书 3:4 多页图文排版、字体压缩、模板美化与日历排期问题；
  2. 新作 2.0 支持多页图文模板与字数门禁，具体模板数量和当前能力以实际产品配置为准；
  3. 支持投喂企业背景、产品资料与品牌调性，让 AI 真正懂你的业务，避免假大空的机器套话。

## 二、使用形式与设备支持
- **使用形态**：免安装、免下载的**电脑网页 Web 端 SaaS** 工具。
- **设备要求**：使用任意电脑浏览器（Chrome / Edge / Safari 等）直接打开即可流畅操作。目前暂不支持手机端直接排版做图（手机屏幕不适合精细排版）。

## 三、目标客群与应用场景
1. **本地高客单与生活服务门店**：美业、轻医美、本地装企、婚纱摄影、月子中心、教培机构等。解决“招不到懂业务的运营、内容假大空、运营离职经验归零”的痛点。
2. **知识博主与咨询顾问**：需要持续输出干货长文、卡片图文、行业方法论与金句轮播图。
3. **B2B / 企业获客团队**：将白皮书、产品参数、案例介绍快速转化为小红书矩阵引流图文。

## 四、核心模块功能详解
1. **策略工坊**：从痛点选题 → 联网搜索补充事实 → 确认大纲方向 → 选择模板与文笔风格 → 自动生成 4~8 页 3:4 轮播图文并排入发布日历。
2. **企业知识库**：可沉淀品牌故事、产品报价、服务流程、合规红线与真实客户案例。
3. **公众号/长文工作台**：支持选题卡片化、自然人声润色与一键导出排版好的公众号富文本 HTML。
4. **小红书私信副驾**：无缝内嵌客服工作台，根据当前会话与知识库精准起草回复，识别并沉淀手机/微信号客资。

## 五、体验、价格与联系方式边界
- 具体价格、体验额度、开通方式和当前功能必须以实际产品配置为准，资料没有明确写明时转人工确认。
- 小红书私信先回答客户当前问题，不把每一句都导向联系方式。
- 只有客户已有明确兴趣且确实需要继续沟通时，才可轻量提出换个更稳定的联系方式。
- 不承诺发送样稿、报告、数据、邀请码、体验额度或其他尚未确认的资产与动作。

## 六、常见高频异议与标准答疑 (FAQ)
- **Q：多少钱？怎么收费？**
  - A：当前资料未确认具体价格时，不自行报价或承诺优惠，请由人工按实际版本确认。
- **Q：手机上可以用吗？有没有小程序或 App？**
  - A：新作 2.0 主要是电脑网页端工具，免下载直接在浏览器打开即可。因为小红书 3:4 多页图文涉及精细的排版、字数门禁和模板调整，电脑大屏操作最轻量顺畅。
- **Q：你们是自动发笔记/自动发私信吗？会不会被封号？**
  - A：默认模式只生成草稿并由操作员确认发送；仍需遵守平台规则，不能承诺账号绝对安全。
- **Q：可以针对我们行业的特定模板定制吗？**
  - A：是否支持行业模板或定制取决于当前实际配置，资料没有明确说明时请由人工确认。
